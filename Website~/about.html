Safety, FAQ, and how to help.

Why Avistry exists

A free, open-source toolkit for VRChat avatars: recolour, paint and fix your avatar inside Unity, in plain words.

  • Safe by design

    Avistry runs in the Unity Editor. The default save makes copies, and the tool collects no telemetry. Update checks and the AI helper are optional.

  • Grown together

    New ideas are discussed on Discord first. Contributions, often built with AI agents, are reviewed and tested in Unity by the maintainers before they ship.

Talk ideas on Discord

What Avistry is, and is not.

  • Editor only

    The tool stays in the Unity Editor

  • No runtime component

    Avistry adds no runtime scripts or components to your avatar. The default save creates a new texture and material copy.

  • No telemetry

    No telemetry. You can check GitHub for updates once or turn on automatic checks. Automatic checks are off by default.

Questions

Safety

Does it change my original textures?

Saving creates a new PNG with an _ats suffix and leaves the source image intact. By default, Avistry also copies the material. Choose “PNG + update material” only if you want to change the existing material.

Is anything uploaded with my avatar?

No. It is an editor-only package, so none of it is included in your avatar or VRChat upload.

Does it send any data?

Avistry has no telemetry. If you check for updates, it asks GitHub for the latest release. Automatic checks are off by default. If you enable the separate AI helper, your AI app can send part, material and texture names to its service. Pictures require your permission, either for one request or until Unity closes.

Shaders

Which shaders does it support?

Quick recolour works with Poiyomi and lilToon. You can also select and paint colour textures used by other shaders. Normal maps cannot be painted. Quick material offers controls for Poiyomi, lilToon, Unity Standard and supported URP Lit materials.

Avatars

Can I use it on a bought avatar?

Yes. The default save creates a new texture and material copy in Assets/Avistry/Output. Check the avatar’s terms before sharing edited textures.

Can an AI app help me with it?

Yes. With the optional MCP for Unity package, your AI app can recolour and add layers while you watch. The helper starts off. You control whether it can save files or share a picture. The README explains how to set it up.

Install

What do I need to run it?

Unity 2022.3, the version VRChat uses. It needs no other packages; Poiyomi and lilToon unlock extra features if you have them installed.

How do I update or remove it?

Update with the same method you installed with: in VCC pick the new version under Manage Project, or import the newer Unity package. To remove it, press − in VCC or delete Packages/com.avistry.toolkit.

I found a bug or have an idea

Please open an issue on GitHub. A screenshot or the Unity Console message helps a lot.

How this was made

Avistry is built with the help of an AI assistant. The maintainers read and review the code, test every feature in a real Unity Editor and fix what breaks. This catches a lot, but it is not a guarantee. If you find a problem, please open an issue.

How to help

  • Read and review
