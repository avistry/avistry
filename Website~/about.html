Safety, FAQ, and how to help.

Why Avistry exists

A free, open-source toolkit for VRChat avatars: recolour, paint and fix your avatar inside Unity, in plain words.

  • Safe by design

    It never overwrites your originals, lives only in the Unity Editor and sends no data. These are rules in the code, not settings.

  • Grown together

    New ideas are discussed on Discord first. Contributions, often built with AI agents, are reviewed and tested in Unity by the maintainers before they ship.

Talk ideas on Discord

What Avistry is, and is not.

  • Editor only

    It lives in the Unity Editor. Nothing goes into your upload.

  • No runtime component

    No script, component or assembly is added to your avatar. Saving makes new files and never overwrites yours.

  • No telemetry

    No telemetry. The only network call is an optional update check that asks GitHub for the latest version number, and it is off until you turn it on.

Questions

Safety

Does it change my original textures?

No. Saving always creates a new PNG with _ats added to the name. Your original files are never overwritten.

Is anything uploaded with my avatar?

No. It is an editor-only package, so none of it is included in your avatar or VRChat upload.

Does it send any data?

No. Avistry has no telemetry. Its only network call is an optional update check, off until you turn it on, that asks GitHub for the latest version number and sends nothing about you or your project. The optional AI helper is separate: it works through your own AI app, which sends part and material names to its service, and pictures only after you click Allow.

Shaders

Which shaders does it support?

Quick recolour works with Poiyomi and lilToon materials. Selecting and painting work on any texture, whatever the shader. Quick material controls also need Poiyomi or lilToon.

Avatars

Can I use it on a bought avatar?

Yes. Avistry saves new files next to the ones you bought, so the originals stay as they came. Check the avatar's terms before you share edited textures.

Can an AI app help me with it?

Optionally. With MCP for Unity (a separate free package), an AI app can recolour and add layers while you watch. It starts off, saving and pictures wait for your Allow, and the README has the steps and notes.

Install

What do I need to run it?

Unity 2022.3, the version VRChat uses. It needs no other packages; Poiyomi and lilToon unlock extra features if you have them installed.

How do I update or remove it?

Update with the same method you installed with: in VCC pick the new version under Manage Project, or import the newer Unity package. To remove it, press − in VCC or delete Packages/com.avistry.toolkit.

I found a bug or have an idea

Please open an issue on GitHub. A screenshot or the Unity Console message helps a lot.

How this was made

Avistry is built with the help of an AI assistant. The maintainers read and review the code, test every feature in a real Unity Editor and fix what breaks. This catches a lot, but it is not a guarantee. If you find a problem, please open an issue.

How to help

  • Creators test

    Use it on real avatars and report what breaks.

  • Read and review

    Pull requests are welcome. The maintainers review every one and test it in Unity.

  • Share your look

    Made a look you love? Share it on our Discord. With your permission, we may show it here.

Get it

Your avatar. Your colours.

VCC (recommended)

Get it in VCC
  1. Select Get it in VCC. If nothing happens, copy the listing URL below and add it in VCC under Settings > Packages > Add Repository.
  2. Open your avatar project in VCC, go to Manage Project and select + next to Avistry.
  3. In Unity, open Tools > Avistry > Textures.

VCC did not open? Copy the listing URL and add it under Settings > Packages > Add Repository.

.unitypackage

Download .unitypackage
  1. Download the .unitypackage from the button above or from GitHub Releases.
  2. With your project open, drag the file into the Project window, or choose Assets > Import Package > Custom Package. Then select Import.
  3. In Unity, open Tools > Avistry > Textures.
Git URL
  1. In Unity, open Window > Package Manager.
  2. Select +, choose Add package from git URL and paste the URL below.
