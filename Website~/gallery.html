    Task: make the hair red and keep the original file.

    In Avistry: {n} steps

    1. Open Tools > Avistry > Textures and pick the avatar.
    2. In the Colour tab, click the hair on the model.
    3. Drag the Hue bar.
    4. Select Save. A new PNG and a material copy are made and put on the avatar.

    With Photoshop: {n} steps

    1. Find which texture the hair uses: select the mesh, open its material, find the image.
    2. Copy the PNG so the original stays safe.
    3. Export the hair's UV layout from Blender, so you know which pixels are hair.
    4. Open the PNG copy in Photoshop and place the UV layout on top as a guide.
    5. Select the hair pieces along the guide.
    6. Add a Hue/Saturation layer to the selection and shift the hue.
    7. Hide the guide and export a PNG.
    8. Back in Unity, duplicate the material.
    9. Put the new PNG in the copy's main texture slot.
    10. Put the material copy on the avatar.
    11. Check it in the Scene. If an edge or a wrong piece shows, go back to step 5.

    This is one common route. Painting by eye skips the UV export but is less exact.

    How these pictures were made.

    Avistry saved the colours and textures. The tattoos are Avistry paint layers (ink, chrome and a bright Add layer) with a normal map made by Avistry, all saved in the texture. Glow, sparkle and the horn tint are shader values set by hand; lights, backdrop and pose are set up in Unity.

    • The face, horns and wing cut-out over the home picture is cut from the same render. It is only there for depth.
    • Poses are set for the photo. The arm view swings the near wing back, and the phone back view folds the wings up to fit.
    • The Project window picture is a real Unity window with a sample hair texture. Labels and the caption were added on top.
    • The tool loops are recorded in Avistry. Cursors, labels and enlarged controls are added on top, and the normal-map and Scene-bar shots use extra lights.

    Get it

    Your avatar. Your colours.

    Free. Editor only. Your originals stay as they are.

    VCC (recommended)

    Get it in VCC
    1. Select Get it in VCC. If nothing happens, copy the listing URL below and add it in VCC under Settings > Packages > Add Repository.
    2. Open your avatar project in VCC, go to Manage Project and select + next to Avistry.
    3. In Unity, open Tools > Avistry > Textures.

    VCC did not open? Copy the listing URL and add it under Settings > Packages > Add Repository.

    .unitypackage

    Download .unitypackage
    1. Download the .unitypackage from the button above or from GitHub Releases.
    2. With your project open, drag the file into the Project window, or choose Assets > Import Package > Custom Package. Then select Import.
    3. In Unity, open Tools > Avistry > Textures.
    Git URL
    1. In Unity, open Window > Package Manager.
    2. Select +, choose Add package from git URL and paste the URL below.
